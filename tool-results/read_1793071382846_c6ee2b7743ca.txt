  1439→### Fast-performance plan and complete Proofing Off
  1440→
  1441→**Current Off behavior, exact offline file:** `proofing-off-file.cjs` / `proofing-off-file-result.json` opens the unmodified blank file in an isolated offline headless context. The bottom `#stSpell` is CSS-hidden, so the test uses the real Review ribbon control. Off keeps marks absent while typing, but `the` still becomes `The` through capitalization. Reload shows the ribbon button aria state back On and starts Harper again; the Review pane is not visible at that snapshot. The hidden status button temporarily differs from the ribbon after reload; no visible-bottom synchronization claim is made. Worker interception records only construction, message type and termination, not archive payloads. Another unclassified worker was also observed; aggregate worker count is not treated as Harper RAM. Current underline-only semantics are recorded as a requirement gap/optimization, not inflated into an additional pre-existing confirmed bug.
